RULE PROPOSAL / BR

마지막 보급창

4인 개인전 · 생존 120초 + 안내·결과 20초, 총 140초 목표

거대한 폭풍 항구에서 수직 엄폐와 보급 위험을 선택하는 짧은 배틀로얄. 먼 바다는 배경이며 무한 야외 맵이 아니다.

시작
서로 바로 보이지 않는 4개 시작 포켓에서 같은 기본 소총·체력·탄약으로 출발. 중앙 상자는 추가 탄약/회복/보호 장비만 제공하며 등급 뽑기로 승패를 결정하지 않는다.
진행
엄폐 사이로 이동 → 위험한 보급 지점에서 장비 보완 → 선체 위/아래로 다른 사격 각도 확보 → 줄어드는 안전 구역에서 마지막까지 생존.
조작
WASD/마우스 이동·조준, 좌클릭 사격, 우클릭 조준 확대, R 재장전, E 가까운 보급품, Space 작은 점프. 장비·조준 흔들림은 실제 팔 도달 범위와 1인칭 가독성 우선.
승패
마지막 생존자가 즉시 승리. 120초에 여러 명 생존하면 현재 체력 비율 → 상대에게 준 유효 피해 순으로 비교하고 같으면 공동 순위. 같은 판정 틱의 마지막 상호 처치는 공동 순위로 처리한다.
실패와 복귀
쓰러지면 이번 라운드 재등장 없이 관전. 초반 탈락의 대기 시간은 남은 120초 이내이며 관전자는 숨은 상대 위치를 전달할 수 없다. 낙수/지형 밖 탈출은 짧은 경고 뒤 일반 피해 판정, 안전 구역으로 무료 순간이동하지 않는다.
막힘 방지
30/60/90초 수축을 5초 먼저 예고하고 105초까지 마지막 구역 완성. 원 중심은 사전에 검증한 도달 가능한 지면 앵커만 사용한다. 위층에만 유리한 마지막 원, 물 위 원, 막다른 길 스폰 금지. 이탈 봇은 같은 시야·소리만 이용한다.

RULE PROPOSAL / SW

뒤집힌 결투장

4인 개인전 우선 · 대결 90초 + 안내·결과 20초, 총 110초 목표

체력만 깎는 결투보다 경사와 위치를 이용한 검·방패 밀어내기. 2대2는 별도 후속 변형이다.

시작
전원 같은 검·방패로 네 안전 포켓에서 시작. 경기 중 바닥 경사는 고정하고 카메라는 수평을 유지한다. 기존 둥근 몸체를 검/방패에 맞춰 찌그러뜨리지 않는다.
진행
검으로 견제 → 방패로 받아내기 → 상대의 회복 순간에 짧게 밀기 → 낮은 쪽 경계 밖으로 떨어뜨리기 → 재등장한 상대와 다시 대결.
조작
좌클릭 검 공격, 우클릭 방패, E 짧은 밀기, WASD 이동, Space 작은 점프. 밀기 쿨다운 3초 초안. 공격은 시작·접촉·회복이 읽히도록 하되 모션 전체 템포는 1.5배 기준.
승패
링아웃 1회 1점, 먼저 5점 또는 90초 최고 점수 승리. 같은 점수면 공동 순위. 추락 전 3초 안에 마지막으로 유효한 밀침을 준 상대가 점수를 얻는다.
실패와 복귀
추락자는 3초 후 가장 비어 있는 복귀 포켓에 재등장. 2초 보호는 공격 시 해제. 상대 접촉 없이 스스로 떨어지면 아무도 점수를 얻지 못한다. 방패는 3회 유효 방어 뒤 1초 무너짐, 비방어 2초마다 1회 회복하는 임시안.
막힘 방지
장식 승리 종/입구는 경기 중 접근 불가. 벽·엄폐에 끼여 무적이 되지 않게 복귀 판정. 매번 같은 낮은 포켓에서 부활하지 않는다. 이탈 봇은 동일 공격 간격과 방패 제한을 지킨다.

RULE PROPOSAL / BC

살아 있는 체스판

2대2 팀 턴제 · 대국 180초 + 안내·결과 20초, 총 200초 목표

네 토끼가 직접 체스말이다. 손으로 작은 체스말을 움직이는 테이블 게임과 구분한다. 정통 체스 전체 룰을 재현하는 모드는 아니다.

시작
6×6칸, 양끝 왕관 거점 내구도 각 2. A1→B1→A2→B2 순환, 한 행동 최대 8초. 직선 1–2칸 / 대각 1–2칸 / L자 2+1칸 중 역할을 선택한다. 구체 시작 좌표는 BC-board-layout.json의 임시안.
진행
자기 턴에 유효 칸 확인 → 하나를 고르면 토끼 몸이 그 칸으로 이동 → 상대 칸이면 상대를 잡기 → 길을 열어 적 왕관 공격. 자기 차례에 이동 대신 역할 변경 또는 패스도 가능하다.
조작
마우스로 칸 바라보기, E 선택/확정, 1/2/3 역할 변경 선택(한 턴 소모). 취소는 확정 전 가능. 이동은 한 번에 확정하고 단순 이동 중 카메라를 강제로 돌리지 않는다. 턴 밖에는 자기 칸 안에서만 시점과 작은 위치 조정.
승패
유효 이동으로 적 왕관 칸에 도달하면 내구도 1을 깎고 자기 출발 칸으로 돌아온다. 왕관 0 즉시 팀 승리. 시간 종료는 왕관 내구도 → 잡은 상대 횟수로 비교하고 같으면 무승부.
실패와 복귀
잡힌 토끼는 다음 자기 턴 시작 때 빈 자기 진영 뒷줄 칸을 골라 복귀하며 그 턴 행동을 정상 수행한다. 빈 복귀 칸이 없으면 대기, 4행동 연속 팀 상태 변화가 없으면 무승부로 종료. 시간 초과는 패스.
막힘 방지
같은 편이 있는 칸과 자기 왕관 칸에는 이동 불가. 직선·대각은 중간 점유 칸을 넘지 못하고 L자만 넘는다. 적 왕관 칸도 이동 역할에 맞아야 공격 가능. 아군/적이 점유한 목표 경로와 유효 칸을 1인칭 바닥 표시로 구분한다. 이탈 봇도 같은 합법 행동만 선택한다.

시작
진영별 2명. 방패 미니언 또는 원거리 미니언 중 하나를 고르고 코어 앞에서 시작한다. 기존 토끼의 몸체·얼굴을 유지하고 장비만 독립 착용한다.
진행
아군 자동 미니언 파도와 함께 본선을 밀기 → 개울·뿌리 샛길로 옆을 찌르기 → 상대 포탑 파괴 → 씨앗 코어 공격. 자동 미니언은 작은 동행 부대이며 플레이어 역할을 대신하지 않는다.
조작
WASD 이동, 마우스 시점/조준, 좌클릭 기본 공격, 우클릭 방패 또는 짧은 견제 기술. Space 작은 점프. 시점은 1인칭 유지.
승패
상대 포탑을 파괴해야 코어가 노출된다. 코어 파괴 즉시 승리. 시간 종료는 코어 남은 체력 비율 → 포탑 체력 비율 순으로 비교, 모두 같으면 무승부.
실패와 복귀
쓰러지면 6초 뒤 자기 코어에서 재등장. 2초 보호는 공격 시 즉시 해제. 장비 성장/전투 재화는 라운드 한정이며 영구 스킨·저장 데이터를 지우지 않는다.
막힘 방지
기지 안 공격과 무한 스폰 킬을 막고, 부활은 움직일 공간이 있는 앵커로 배치한다. 이탈자는 같은 정보·사거리의 봇이 대신한다.

시작
전원 도착 턱에서 시작. 3구간 등반과 2개 중간 휴식 턱. 첫 성공자가 턱의 고정점을 열면 팀 체크포인트가 된다.
진행
손잡이를 골라 좌우 번갈아 잡기 → 가까운 턱에서 쉬기 → 위에서 동료 당겨주기 → 정상 구조 신호에 네 명 집결.
조작
좌/우클릭은 왼손/오른손 잡기·놓기, WASD는 몸의 이동 방향. E는 근거리 동료 구조/고정점. 도달 범위 밖에는 손을 늘리지 않고 잡기 불가 표시.
승패
제한 시간 내 네 명 모두 정상 안전 구역에 들어가면 협동 성공. 도착자를 제외하고 관전자나 봇을 인원에서 누락시키지 않는다.
실패와 복귀
추락은 팀 구조 로프 1회를 소모해 5초 후 마지막 열린 안전 턱으로 복귀. 팀 구조 3회 초안이며 네 번째 추락 또는 시간 종료에 실패. 전원 매달린 상황도 동일 자동 구조 규칙을 적용한다.
막힘 방지
체크포인트는 영구 열린 상태로 유지. 이탈자는 봇이 오르며, 되돌아올 수 없는 몸 끼임은 동일 구조 1회로 회수. 잡고 쉬는 시간과 피로 수치는 실제 리그/조작 확인 후 결정한다.

시작
10쌍의 좌우 발판 중 매 쌍 한 칸이 버틴다. 경로는 라운드 시작 때 고정하며 네 명에게 동일. 이미 확인한 발판 표시를 팀이 공유한다.
진행
현재 칸에서 다음 좌우 칸을 두드려 단서 확인 → 경로를 선택해 점프 → 동료에게 안전 칸 알려주기 → 전원 출구 도달.
조작
WASD/마우스/Space 이동·도약, E 근거리 두드리기(0.35초 초안), 핑으로 경로 공유. 음향 단서는 같은 의미의 화면 진동 패턴도 제공한다.
승패
120초 안에 전원 출구에 도달하면 성공. 세부 시간·점프 거리는 실제 캐릭터 도약 측정으로 조정한다.
실패와 복귀

막힘 방지
동료 밀기 충돌은 끄고 자리 겹침은 짧게 허용해 길막을 막는다. 미확인 칸으로 구조하지 않는다. 케이블/테두리는 보행 경로가 아니며 가장자리 꼼수를 검증한다. 이탈 봇도 들은/공유된 단서만 이용한다.

고장 난 궤도 정비실

정비원 3 대 방해꾼 1 · 임무 180초 + 안내·결과 20초, 총 200초 목표

서로 다른 층에서 정비하는 행동과 남은 흔적으로 방해꾼을 판단한다. 개인 역할은 본인에게만 보인다.

시작
배선·냉각·통신 세 구역에 총 8개 임무 배분. 정비원은 서로 다른 임무를 받고 방해꾼은 가짜 업무와 방해 장치를 받는다.
진행
임무와 증거 확인 → 통로에서 다른 사람 행동 관찰 → 고장 복구 또는 중앙 종으로 토론 → 수리 완료 또는 방해꾼 격리.
조작
E 짧은 삽입/회전/접속 상호작용. 역할 행동은 근거리 문맥 입력. 투표는 버튼으로 가능하며 음성 대화가 필수가 아니다.
승패
정비원은 8개 임무 완료 또는 올바른 격리 투표로 승리. 방해꾼은 시간 내 수리를 막거나 미복구 고장으로 정거장 안정성을 0으로 만들면 승리.
실패와 복귀
